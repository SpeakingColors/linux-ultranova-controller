UltraNova Controller install, remove and use (works fully offline)
=====================================================

Windows
  Run windows\UltraNovaController-Setup.exe. It installs two things: the VST3 plugin for your DAW
  (C:\Program Files\Common Files\VST3, fixed location, all users) and the standalone app plus manual
  (C:\Program Files\Studio 87\UltraNova Controller, the folder the installer asks about).
  Windows may show a blue "unknown publisher" screen because the installer is not signed:
  click "More info", then "Run anyway".
  Remove: Settings > Apps > UltraNova Controller > Uninstall.

macOS
  Open macos\UltraNovaController-macOS.pkg. It installs the VST3 plugin, the standalone app, the manual and "Uninstall UltraNova Controller".
  The installer is not notarized: if macOS blocks it, open System Settings > Privacy & Security and choose "Open Anyway".
  Remove: open "Uninstall UltraNova Controller" in the Applications folder.

Linux, DAW installed as a Flatpak (for example Bitwig, Reaper or Ardour from Flathub)
  1. Your DAW should use the org.freedesktop.Platform 25.08 runtime (check with: flatpak info <DAW id>, Runtime line).
  2. Install the file from the linux folder:
       flatpak install --user linux/UltraNovaController-flatpak-25.08.flatpak
  3. Restart the DAW and rescan plugins.
  Remove: flatpak uninstall --user org.freedesktop.LinuxAudio.Plugins.UltraNovaController   (removes the plugin completely)

Linux, DAW installed natively
  Extract linux/UltraNovaController-linux-vst3.tar.gz into ~/.vst3  (create the folder if needed), then rescan plugins.
  Remove: delete the "UltraNova Controller.vst3" folder from ~/.vst3.


Settings: this plugin has no preset files. Its values are saved inside your DAW project.
Manual: UltraNovaController-manual.pdf (what every control does, and the honest status of the MIDI map).
Checksums: SHA256SUMS.
